# Image credits

All photos in `greentastic/static/` (except the vendored libraries) come from [Wikimedia Commons](https://commons.wikimedia.org/).
Only files under **CC0 / public domain**, **CC BY** or **CC BY-SA** licenses were used (no NonCommercial or
NoDerivatives licenses). The licenses were read from the Commons file metadata on the day of download
(2026-10-02) - please re-check the linked file page before a public release.

Changes made to every file: converted to RGB, scaled down (max. 1280 px wide, hero images 1920 px, `.png` files 900 px)
and recompressed. The file names are kept so that the demo data and templates keep working; they do not
describe the original files.

* **CC0 / public domain**: no attribution required, listed here anyway.
* **CC BY**: attribution (author, license, link, changes) is given in the table below.
* **CC BY-SA**: as CC BY; in addition the *adapted image* (the file in this repository) is licensed under the same
  CC BY-SA license, not only the original.
